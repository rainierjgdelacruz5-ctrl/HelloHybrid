Hello Kaffi setup
1. Put your Firebase service account key at backend-sync/serviceAccountKey.json
   (Firebase Console > Project settings > Service accounts > Generate new private key). Keep it secret.
2. npm install
3. npm start
4. Customers: http://localhost:3000   Staff: http://localhost:3000/pos/login.html
   Demo staff logins: cashier/cashier123, admin/admin123 (change before going live)
Always open the site via http://localhost:3000 (not by double-clicking the HTML files).
